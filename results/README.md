# Results

- `attention/`: attention matrices, plots, and summaries.
- `feature_importance/`: feature-importance tables.
- `figures/`: training curves and presentation figures.
- `metrics/`: serialized summaries and model metrics.
- `predictions/`: prediction exports from future cleaned runs.

Historical bundles remain beside their code under `experiments/archive/` to preserve provenance and avoid filename collisions. Unambiguous portfolio checkpoints are stored in `checkpoints/`.
